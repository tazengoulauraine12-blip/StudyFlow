## 📝 Über das Projekt (Project Overview)

**StudyFlow** ist eine webbasierte Anwendung zur effizienten Steuerung und Verwaltung studentischer Gruppenprojekte. Das System hilft Studierenden dabei, Aufgaben zu strukturieren, Projektfortschritte zu verfolgen und die Zusammenarbeit innerhalb von Hochschulprojekten zu optimieren.

### ✨ Hauptfunktionen (Key Features)
- **Benutzerverwaltung:** Registrierung, Authentifizierung und geschützter Login für Studierende.
- **Projektverwaltung:** Erstellung, Bearbeitung und Übersicht von Gruppenprojekten.
- **Aufgabensteuerung (Task Management):** Erstellung von Tasks, Zuweisung zu Projektmitgliedern und Statusaktualisierungen (z. B. *To Do*, *In Progress*, *Done*).
- **Dashboard & Statusübersicht:** Übersichtliche Darstellung aller aktiven Fristen und Meilensteine.

---

## 🛠️ Tech Stack & Architektur

Das Projekt basiert auf einer sauberen **MVC-Architektur** (Model-View-Controller) zur Trennung von Anwendungslogik, Datenhaltung und Benutzeroberfläche.

- **Backend:** Java, Jakarta Servlets, JSP (JavaServer Pages)
- **Frontend:** HTML5, CSS3, JavaScript
- **Datenbank:** MySQL / MariaDB
- **Server:** Apache Tomcat
- **Build & Version Control:** Git, GitHub
